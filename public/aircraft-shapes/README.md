# Aircraft shapes

The SVG files in `shapes/` are vendored unmodified from
[RexKramer1/AircraftShapesSVG](https://github.com/RexKramer1/AircraftShapesSVG)
("Aircraft shapes (Top View) for ADSB-Viewers in SVG-Format", by RexKramer1
and the BelugaProject authors), licensed under the **GNU General Public
License v3.0** — see `LICENSE` in this directory for the full text.

This app's own code (everything outside this directory) is MIT-licensed —
see the repo root `LICENSE`. These SVGs are a separate, unmodified
third-party asset set displayed by the app, not linked/compiled code; they
retain their original GPL-3.0 license and are redistributed here with that
license and this attribution intact, per its terms.

Filenames match ICAO type designators (e.g. `B738.svg`) and are rendered
in-app via a CSS `mask-image` (see `components/map/overlay/PlaneCard.module.css`'s
`.shapeIcon`) so the plain white silhouettes can be tinted to this app's own
rarity-tier accent colors without modifying the source files. The
type-designator → filename mapping is generated by
`scripts/generate-aircraft-shapes-manifest.mjs` into
`components/map/data/aircraftShapes.json` — re-run manually if this
directory's contents change; it isn't part of the build.

`Unidentified.svg` is used as the fallback shape for any type designator
with no matching file, or when the aircraft has no known type designator at
all.
